# GuitarShop

Простой интернет-магазин гитар для практики JavaScript.

### Возможности
- Каталог акустических гитар
- Сортировка товаров по цене
- Добавление и удаление товаров из корзины
- Подсчёт общей стоимости
- Сохранение корзины в Local Storage

### Технологии
HTML, CSS, JavaScript
